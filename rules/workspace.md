# 临时文件与工作区

**何时加载**：需要写脚本、抓取数据、导出、截图、记录调研结论或做一次性验证时。

- 一次性脚本、抓取脚本、调研输出、日志、截图、导出数据一律写进 `/.dsh-work/`（已 gitignore）或系统临时目录，不落在仓库根或 `packages/` 里。
- 不为一次任务新建 `scripts/` 目录；仓库现有的 `.github/`、`examples/` 只放长期有用的东西。
- 仓库根只允许长期文件；新增根文件前先自问"这个文件删掉仓库是否受损"，答否就进 `.dsh-work/` 或 `docs/`。
- 验证完成后清理临时产物；仅 `.dsh-work/` 内的可保留（它不进 git），但仍应保持可辨认的目录名。
